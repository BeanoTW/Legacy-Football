# Polish, Personality & Football Identity

This phase is about making Legacy Football feel like a football club rather than a generic management dashboard.

## Product rule

Every major screen should communicate at least one of:

- **Identity** — this club should look and feel like *this* club.
- **Place** — ground, stands and local setting should have character.
- **People** — managers, directors, staff, players and supporters should speak and matter as individuals.
- **Context** — football information should explain why the next match, decision or run matters.
- **Memory** — seasons, records, milestones and returning people should leave a trace.

A useful polish test is: **could this exact screen belong to any generic management app?** If the answer is yes, it is not finished.

## Current implementation order

1. Home and chairman shell polish
2. Club identity and football-context presentation
3. Named voices and football copy
4. Manager tactical identity and squad suitability
5. Manager-led recruitment needs
6. Supporter/board reaction and micro-storytelling
7. Records, milestones and callbacks
8. Consistency pass across Squad, Transfers, Scouting, Inbox, Staff, Competitions, Finances and Board
9. Hands-off 2D match viewer

## Match viewer rule

**The chairman watches football. The manager manages it.**

The 2D viewer should visualise the authoritative match simulation rather than become a second tactical game. Players are represented as dots on a top-down pitch, with believable formation shape and event-driven movement. The chairman may pause or change playback speed, but does not make substitutions or tactical changes.

The viewer should make manager identity visible: formations, compactness, directness, pressing and in-match changes come from the appointed manager and match state.

## Core game-feel loop

**Anticipation → Continue → event → consequence → reaction → next decision.**

The Advance screen should continually give the player a reason to press Continue by showing what is about to happen and making the club react when it does.
